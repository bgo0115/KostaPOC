# 아이디어 — 사내 도서 대여

## 해결할 문제

팀 서가의 책을 누가 빌려 갔는지 아무도 모른다. 대여 기록은 종이 노트에 적고, 이미 빌려 간 책을 찾으러 갔다가 헛걸음하는 일이 잦다.

## 가설

간단한 웹 화면에서 책 목록과 대여 상태를 보고, 이름만 입력해 빌리고 반납할 수 있으면 헛걸음이 없어진다.

## 이번 POC 로 확인할 것

Claude Code 와 git worktree 로 백엔드 · 프론트엔드를 나눠 만들어, 하루 안에 「목록 → 대여 → 이미 빌린 책 거부 → 반납」 흐름이 동작하는지 확인한다.

## 사용자

- 사내 직원 30명 내외
- 로그인 없이 이름만 입력

## 참고

- 서가의 책은 처음에 5권으로 시작한다
- 기술 스택 · 성공 기준 · 범위는 2차시에 정한다
