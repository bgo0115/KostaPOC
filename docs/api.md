# API 명세 — 사내 도서 대여 POC

`docs/design.md` 3절을 바탕으로 정리한 백엔드 · 프론트엔드 사이의 계약이다. 이 문서와 `design.md` 가 다르면 `design.md` 를 먼저 고치고 이 문서를 맞춘다.

## 공통 규칙

| 항목 | 내용 |
|---|---|
| 주소 접두사 | 모든 경로는 `/api` 로 시작한다 |
| 서버 포트 | 3000 (화면은 Vite proxy 로 `/api` 를 전달) |
| 본문 형식 | 요청 · 응답 모두 JSON |
| 오류 형식 | `{"error": "한국어 메시지"}` 로 통일. 화면은 `error` 값을 그대로 보여 준다 |
| 인증 | 없음 |

### 책 객체

| 필드 | 타입 | 설명 |
|---|---|---|
| id | 정수 | 책 번호 |
| title | 문자열 | 책 이름 |
| author | 문자열 | 저자 |
| borrower | 문자열 또는 null | 빌려간 사람. null 이면 대여 가능 |
| borrowed_at | 문자열 또는 null | 빌린 날짜 `YYYY-MM-DD` |
| loan_days | 정수 또는 null | 대여 기간(일) |

대여 중이면 `borrower` · `borrowed_at` · `loan_days` 가 모두 값이 있고, 대여 가능이면 셋 다 null 이다. 반납 예정일은 응답에 없으며 화면이 `borrowed_at + loan_days` 로 계산한다.

## API 요약

| 기능 | 메서드 | 주소 | 성공 | 오류 |
|---|---|---|---|---|
| 목록 조회 | GET | `/api/books` | 200 | 없음 |
| 대여 | POST | `/api/books/:id/rent` | 200 | 400, 404, 409 |
| 반납 | POST | `/api/books/:id/return` | 200 | 404, 409 |
| 상태 확인 | GET | `/api/health` | 200 | 없음 |

## 1. 목록 조회

| 항목 | 내용 |
|---|---|
| 주소 | `/api/books` |
| 메서드 | GET |
| 요청 본문 | 없음 |

**성공 응답 200** — 책 객체의 배열(id 순)

```json
[
  {"id": 1, "title": "클린 코드", "author": "로버트 마틴", "borrower": null, "borrowed_at": null, "loan_days": null},
  {"id": 2, "title": "실용주의 프로그래머", "author": "데이비드 토머스", "borrower": "홍길동", "borrowed_at": "2026-10-30", "loan_days": 14}
]
```

**오류 응답**

| 상태 | 응답 본문 | 조건 |
|---|---|---|
| 404 | 해당 없음 | 대상을 지정하지 않는 API 다 |
| 409 | 해당 없음 | 지키는 규칙이 없다 |

---

## 2. 대여

| 항목 | 내용 |
|---|---|
| 주소 | `/api/books/:id/rent` |
| 메서드 | POST |
| 요청 본문 | `{"name": "홍길동", "days": 14}` |

**요청 본문 필드**

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| name | 문자열 | 예 | 빌리는 사람. 앞뒤 공백은 제거하고, 비면 400 |
| days | 정수 | 아니오 | 대여 기간. 1~30, 생략하면 7 |

**성공 응답 200** — 갱신된 책 1권. 서버가 `borrowed_at` 을 오늘 날짜로 기록한다.

```json
{"id": 1, "title": "클린 코드", "author": "로버트 마틴", "borrower": "홍길동", "borrowed_at": "2026-10-30", "loan_days": 14}
```

**오류 응답**

| 상태 | 응답 본문 | 조건 |
|---|---|---|
| 400 | `{"error": "이름을 입력하세요"}` | `name` 이 없거나 공백뿐 |
| 400 | `{"error": "대여 기간은 1~30일 정수여야 합니다"}` | `days` 가 1~30 의 정수가 아님 |
| 404 | `{"error": "책을 찾을 수 없습니다"}` | 없는 `:id` |
| 409 | `{"error": "이미 대여 중인 책입니다"}` | **핵심 규칙 위반** — 이미 대여 중인 책을 다시 대여. 책의 상태와 대여자는 바뀌지 않는다 |

---

## 3. 반납

| 항목 | 내용 |
|---|---|
| 주소 | `/api/books/:id/return` |
| 메서드 | POST |
| 요청 본문 | 없음 (이름 확인 없이 누구나 반납) |

**성공 응답 200** — 갱신된 책 1권. `borrower` · `borrowed_at` · `loan_days` 가 모두 null 로 돌아온다.

```json
{"id": 1, "title": "클린 코드", "author": "로버트 마틴", "borrower": null, "borrowed_at": null, "loan_days": null}
```

**오류 응답**

| 상태 | 응답 본문 | 조건 |
|---|---|---|
| 404 | `{"error": "책을 찾을 수 없습니다"}` | 없는 `:id` |
| 409 | `{"error": "대여 중인 책이 아닙니다"}` | 이미 대여 가능한 책을 반납 |

## 성공 기준 대응

| 성공 기준 | 호출 | 기대 결과 |
|---|---|---|
| (a) 목록 | `GET /api/books` | 200, 샘플 5권 |
| (b) 대여 | `POST /api/books/:id/rent` | 200, 대여자 · 빌린 날 · 기간이 채워진다 |
| (c) 거부 | 대여 중인 책에 `POST /api/books/:id/rent` | 409 + `이미 대여 중인 책입니다`, 화면에 그대로 표시 |
| (d) 반납 | `POST /api/books/:id/return` | 200, 이후 같은 책 재대여 성공 |
